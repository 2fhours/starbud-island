# 试玩迭代记录

基准是 main `d44a497`，画面 1.8.0。发布提交把画面改成 1.9.0。浏览器试玩使用独立页面，先 `localStorage.clear()`，不碰仓库外的存档。`?test=1` 只缩短对话等待。键盘走动和点击是自然操作。把等级直接改成 14 的那一次标明为夹具。

音乐没有人耳听审。能核对的是：探索时 `audioState.track=explore` 且 `live=4`，进战斗后变成 `battle`，岭上旋律的第一个音与岛上、战斗都不同，音量系数不超过探索。

## 第 1 轮

- 提交：`0696e27`
- 操作：新档，选星旅和叶角鹿，跳过开场，看左上角。截图 `/opt/cursor/artifacts/playtest/r1/01-field.png`
- 问题：芯片只写「委托进行中」，不知道下一步是收服。
- 改动：按岛上和岭上进度显示具体下一步，窄屏允许折行。
- 验证：`npx vitest run src/game/logic.test.ts` 通过。第 10 轮重开后芯片为「去草坡、湖边或苔林收服一只芽灵」。

## 第 2 轮

- 提交：`a700576`
- 操作：用方向键走向最近的电绒鼠。第一次停在大约四十像素外，没有进入遭遇，野生还在走。
- 问题：遭遇距离只有 30 像素，芽灵又会自己挪开。
- 改动：72 像素内芽灵停住，44 像素内进入遭遇。
- 验证：`npx vitest run src/game/maps.test.ts` 通过。第 10 轮用方向键走到电绒鼠后进入了遭遇。

## 第 3 轮

- 提交：`486d352`
- 操作：新档等级是 5。对照岚川的对手配置。
- 问题：试炼是 7 级焰尾狐、8 级岩壳龟、7 级电绒鼠，开场对话没有说要先练习。这一轮没有把试炼打完。
- 改动：改成 6 级焰尾狐和 7 级岩壳龟，对话先说明对手，并建议找青禾。
- 验证：`npx vitest run src/game/maps.test.ts` 通过。设定文档写了这组等级。

## 第 4 轮

- 提交：`db2b48e`
- 操作：开场读 `audioState`，进战斗再读。探索是 `explore` 且正在排程；战斗变成 `battle`。
- 问题：星雾岭和星芽岛共用一段旋律，战胜没有单独的短音。
- 改动：岭上用另一句更慢的旋律，走探索音路，不和战斗叠播。战胜或收服播放 `win`。
- 验证：`npx vitest run src/game/music.test.ts` 通过。没有人耳听审。

## 第 5 轮

- 提交：`6bc16cd`
- 操作：野生战里按钮只有「物理 / 辅助」，战报很快停在「效果不利」。截图 `/opt/cursor/artifacts/playtest/r1/03-battle.png`
- 问题：状态招只有笼统的持续伤害和定身，打不出灼伤、中毒、麻痹、睡眠的差别，敌方也可能对着同一状态反复放。
- 改动：原有 480 个技能按降攻、降防、降速、定身分成四种异常。不叠加。睡眠只跳过 1 回合。麻痹 25% 停手。灼伤的物理攻击再乘 0.85，魔法不乘。伤害公式的其余部分不变。
- 验证：`npx vitest run src/game/ailments.test.ts src/game/system.test.ts src/game/formula.doc.test.ts` 通过。
