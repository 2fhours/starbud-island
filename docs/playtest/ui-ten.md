# 界面十轮

基准是 main `9f8e52b`，画面 1.10.0。这一组只改界面、战斗反馈和背面朝向，不改伤害、暴击、属性倍率、存档键和音乐键。浏览器试玩先 `localStorage.clear()`。`?test=1` 只缩短对话等待。把物种直接改成另一只、或用存档夹具的地方会标明。没有宣称从 1 级自然通关。

朝向是对着 `public/portraits/*-back.jpg` 逐张看的。我方槽位在画面左侧，敌方在右侧。头或胸朝画面左侧的背面，只在我方槽位水平翻转。正后方不翻。图鉴、详情和敌方正面不翻。

## 1.10.1

- 问题：我方背面缩在信息条左侧，敌方正面缩在右侧信息条里，两只不站在同一块地上。叶角鹿原稿已经朝右，焰尾狐和汐纹獭的头朝左。体力数字和法力数字贴在一起，留到 1.10.3。
- 改动：战场左侧放我方背面，右侧放敌方正面。翻转只写在 `.portrait-facing`，位移层是 `.battle-motion`，效果层是 `.battle-fx`。叶角鹿、翠枝鹿、森冕鹿原稿朝右，不翻。焰尾狐、火纹狐、炽焰狐、汐纹獭、潮纹獭、沧澜獭朝左，我方槽位翻转。其余 23 张是正后方，不翻，也不当成已经面向敌方。对战弹窗打开时，提示改到画面上方，免得挡住出招。
- 验证：`npx vitest run src/game/facing.test.ts src/game/portrait.test.ts` 通过。新档选星旅和叶角鹿，跳过开场，走到野生电绒鼠并开战。桌面 1280×800 和 375×812 都看到叶角鹿背面在左、电绒鼠正面在右，叶角鹿没有 `scaleX(-1)`，头朝向右边的电绒鼠。版本号是 v1.10.1。
- 截图：`/opt/cursor/artifacts/playtest/v1101/battle-desktop.png`、`battle-375.png`。原稿和翻转对照是 `flip-compare.png`。
- 限制：正后方的 23 张看不出面朝敌方，没有重绘。这一轮没有打完战斗，也没有换上焰尾狐。体力「81/81」和法力「71/71」仍连在一行。

## 1.10.2

- 问题：要逐张核对翻转后的我方槽位，不能只看原稿。我方和敌方一样大，背面不够靠前。
- 改动：我方立绘比敌方略大，站在同一块地的近处。`scripts/back-contact.mjs` 用游戏样式把 32 张背面放进我方槽位，朝左的必须是 `scaleX(-1)`，朝右和正后方必须是 `none`，对不上就失败。
- 验证：脚本画出 32 张并检查变换。夹具把场上物种改成焰尾狐、露珠蛙、寒泉鲵，不是自然捕捉。焰尾狐翻转后头朝右、尾巴在左，对着电绒鼠。露珠蛙和寒泉鲵不翻转。寒泉鲵尾巴仍偏向一侧，头是正后方，不能当成已经面向敌方。桌面我方信息没有压住按钮，正文不需要滚动。版本号 v1.10.2。
- 截图：`/opt/cursor/artifacts/playtest/v1102/back-contact.png`、`battle-yanwei.png`、`battle-hanquan.png`。
- 限制：接触表和换物种都是夹具。正后方 23 张仍要重绘才能明确朝向。体力法力仍连在一行。
