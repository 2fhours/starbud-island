# 界面十轮

基准是 main `9f8e52b`，画面 1.10.0。这一组只改界面、战斗反馈和背面朝向，不改伤害、暴击、属性倍率、存档键和音乐键。浏览器试玩先 `localStorage.clear()`。`?test=1` 只缩短对话等待。把物种直接改成另一只、或用存档夹具的地方会标明。没有宣称从 1 级自然通关。

朝向是对着 `public/portraits/*-back.jpg` 逐张看的。我方槽位在画面左侧，敌方在右侧。头或胸朝画面左侧的背面，只在我方槽位水平翻转。正后方不翻。图鉴、详情和敌方正面不翻。

## 1.10.1

- 问题：我方背面缩在信息条左侧，敌方正面缩在右侧信息条里，两只不站在同一块地上。叶角鹿原稿已经朝右，焰尾狐和汐纹獭的头朝左。体力数字和法力数字贴在一起，留到 1.10.3。
- 改动：战场左侧放我方背面，右侧放敌方正面。翻转只写在 `.portrait-facing`，位移层是 `.battle-motion`，效果层是 `.battle-fx`。叶角鹿、翠枝鹿、森冕鹿原稿朝右，不翻。焰尾狐、火纹狐、炽焰狐、汐纹獭、潮纹獭、沧澜獭朝左，我方槽位翻转。其余 23 张是正后方，不翻，也不当成已经面向敌方。对战弹窗打开时，提示改到画面上方，免得挡住出招。
- 验证：`npx vitest run src/game/facing.test.ts src/game/portrait.test.ts` 通过。新档选星旅和叶角鹿，跳过开场，走到野生电绒鼠并开战。桌面 1280×800 和 375×812 都看到叶角鹿背面在左、电绒鼠正面在右，叶角鹿没有 `scaleX(-1)`，头朝向右边的电绒鼠。版本号是 v1.10.1。
- 截图：`/opt/cursor/artifacts/playtest/v1101/battle-desktop.png`、`battle-375.png`。原稿和翻转对照是 `flip-compare.png`。
- 限制：正后方的 23 张看不出面朝敌方，没有重绘。这一轮没有打完战斗，也没有换上焰尾狐。体力「81/81」和法力「71/71」仍连在一行。

## 1.10.2

- 问题：要逐张核对翻转后的我方槽位，不能只看原稿。我方和敌方一样大，背面不够靠前。
- 改动：我方立绘比敌方略大，站在同一块地的近处。`scripts/back-contact.mjs` 用游戏样式把 32 张背面放进我方槽位，朝左的必须是 `scaleX(-1)`，朝右和正后方必须是 `none`，对不上就失败。
- 验证：脚本画出 32 张并检查变换。夹具把场上物种改成焰尾狐、露珠蛙、寒泉鲵，不是自然捕捉。焰尾狐翻转后头朝右、尾巴在左，对着电绒鼠。露珠蛙和寒泉鲵不翻转。寒泉鲵尾巴仍偏向一侧，头是正后方，不能当成已经面向敌方。桌面我方信息没有压住按钮，正文不需要滚动。版本号 v1.10.2。
- 截图：`/opt/cursor/artifacts/playtest/v1102/back-contact.png`、`battle-yanwei.png`、`battle-hanquan.png`。
- 限制：接触表和换物种都是夹具。正后方 23 张仍要重绘才能明确朝向。体力法力仍连在一行。

## 1.10.3

- 问题：体力数字和法力数字贴成「77/77法力52/52」。看不出谁先出手。冷却只在数字后面挤一个数。
- 改动：体力和法力各占一行，绿条是体力，蓝条是法力，右边是当前/上限。开战写「我方先出手」或「对方先出手」，比较方式和原来的出手顺序相同，不写公式。护盾、异常、持续、恢复用不同底色。冷却中的技能写「冷却 N」，法力不够写「法力不足」。
- 验证：新档叶角鹿对野生电绒鼠。桌面和 375 宽都能分开读到两行数值。这一场电绒鼠更快，界面写「对方先出手」。正文不滚动，我方信息在按钮上方 29 像素。版本号 v1.10.3。
- 截图：`/opt/cursor/artifacts/playtest/v1103/battle-desktop.png`、`battle-375.png`。
- 限制：375 宽的开场提示还会压住弹窗顶。这一轮没有放出会进入冷却的神级技能，所以没看到冷却徽章。没有改出手计算公式。

## 1.10.4

- 问题：长按只能把说明写进战报，按钮本身看不出正在查看。物理、魔法和辅助的小标都挤在同一套橙色上。
- 改动：按住约 450 毫秒时，技能按钮加上绿色外框，松手或滑动后外框去掉，仍然不出招。物理、魔法、辅助的类别块用不同底色。冷却中的按钮加内框，并写「冷却 N」。法力不够写「法力不足」，按钮不可按。
- 验证：新档叶角鹿对野生。长按第一招，战报出现技能说明，敌方体力仍是 71，阶段仍是 input。松手后外框消失，体力不变。随后夹具把第一招换成「新枝」、法力改成 0、护盾招冷却设为 2：魔法块、法力不足和冷却 2 都能看见。这组法力和冷却是夹具，不是自然耗尽。版本号 v1.10.4。
- 截图：`/opt/cursor/artifacts/playtest/v1104/hold-desktop.png`、`states-desktop.png`。
- 限制：没有在 375 宽上再长按一次。数字键出招留到后面的全流程脚本。

## 1.10.5

- 问题：出招只有战报，物理和魔法看起来一样。血条在「使用了」这一句就已经是结算后的数。
- 改动：物理攻击在受击方闪一条刀光，魔法攻击闪一个圆环，颜色用招式属性的公开颜色。位移在 `.battle-motion`，刀光在 `.battle-fx`，不写在翻转层上，名字不跟着翻。回合结束清掉这些标记。伤害公式没改。
- 验证：`npx vitest run src/game/fx.test.ts` 通过。新档叶角鹿对野生，不加快对话。叶刃打出时敌方槽位 `data-fx=physical`，颜色是阳木的 `#67b85a`，我方位移动画是 `lunge-right`，背面没有镜像，名字的 transform 是 none。这一下敌方体力从 71 降到 69。战报停在「叶角鹿使用了叶刃」时特效还在，等回合日志走完后 `data-fx` 被清掉。夹具把第一招换成「新枝」后再打，敌方槽位变成 `magic`。版本号 v1.10.5。
- 截图：`/opt/cursor/artifacts/playtest/v1105/physical.png`、`magic.png`。新枝那一张是夹具。
- 限制：血条仍在整回合算完后立刻显示结果，还没跟每一句战报对齐。这留给 1.10.6。没有人眼看刀光停留的完整 0.42 秒，截图停在出手那一句。

## 1.10.6

- 问题：战报还停在「使用了」时，血条已经是整回合打完的数。暴击、治疗、护盾没有单独的数字。
- 改动：从出手前的体力记起，每一句战报按里面的伤害、治疗、反震、法力增减改显示中的条。暴击写「暴击 N」，普通伤害写「-N」，治疗写「+N」，护盾和强化另有字。数字挂在立绘槽上，不放进翻转层。受击和暴击的晃动在 `.battle-motion`。回合结束改回结算后的真实体力。不改暴击率和伤害公式。
- 验证：新档叶角鹿对野生岩壳龟，我方先出手。停在「叶角鹿使用了叶刃」时敌方仍是 109/109。下一句「造成 12 点伤害」，条变成 97/109，槽上是「-12」。另一次把暴击追加设成 1、掷子设成 0.2，这是夹具，公式仍把暴击率封在 0.5。战报是「暴击，造成 75 点伤害」，条从 105/105 到 30/105，字是「暴击 75」，类名 `floater-crit`，不在 `.portrait-facing` 里面。版本号 v1.10.6。
- 截图：`/opt/cursor/artifacts/playtest/v1106/hit-line.png`、`crit-line.png`。
- 限制：护盾标签仍读当场数据，可能比战报早一拍。暴击那一次改过暴击追加和掷子。没有把治疗和护盾的字各截一张。
