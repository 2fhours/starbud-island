# 界面十轮

基准是 main `9f8e52b`，画面 1.10.0。这一组只改界面、战斗反馈和背面朝向，不改伤害、暴击、属性倍率、存档键和音乐键。浏览器试玩先 `localStorage.clear()`。`?test=1` 只缩短对话等待。把物种直接改成另一只、或用存档夹具的地方会标明。没有宣称从 1 级自然通关。

朝向是对着 `public/portraits/*-back.jpg` 逐张看的。我方槽位在画面左侧，敌方在右侧。头或胸朝画面左侧的背面，只在我方槽位水平翻转。正后方不翻。图鉴、详情和敌方正面不翻。
