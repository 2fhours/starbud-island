# 星芽岛设定索引

这里记录已经写进代码的规则。画面版本见 `package.json`，当前是 1.10.9。存档信封版本是另一套数字，见存档文档。

界面十轮记录在 [试玩记录](../playtest/ui-ten.md)。

游戏里不打开这些文档。玩家能看到体力、法力、等级、五行属性名、五项可见能力及其推导值、技能说明、进化条件和是否满足、战斗结果和捕捉成功率。种族值和个体值不出现在界面里。

| 文档 | 内容 |
| --- | --- |
| [设定](setting.md) | 芽灵、十二属性、两张地图、技能结构、对战流程、音乐、静态立绘、玩家能看见什么 |
| [进化](evolution.md) | 三十二种形态、进化条件、种族成长、焰心石和清风铃 |
| [异常状态](ailments.md) | 灼伤、中毒、麻痹、睡眠的回合、上限和敌方选招 |
| [计算公式](formulas.md) | 变量、默认参数、上下限、取整顺序、随机分布和可复核样例 |
| [存档与版本](saves.md) | 存档键、旧档迁移、画面版本和存档版本 |

未实施、不要当成现规则的部分集中写在设定文档的「未实施」一节，公式文档里不再另造一套数。
