# 异常状态

状态类技能仍然是原来的 480 个技能之一，不新增招式表。按技能上已经写好的效果分成四种异常。五行克制、物理和魔法的攻防选择、先算攻击加成再减伤，都不变。

| 技能 | 异常 | 规则 |
| --- | --- | --- |
| 状态里降低攻击的持续伤害 | 灼伤 | 持续回合用技能上的回合数，再中一次不叠加。攻击下降只有这一招原来的能力阶 −1，只降一次。灼伤本身不再把物理攻击乘 0.85，也不再额外降攻。回合结束损失 `max(1, min(floor(体力上限 / 16), floor(体力上限 * 0.08)))`。只剩 1 点体力时，这一下会让它倒下。 |
| 状态里降低防御的持续伤害 | 中毒 | 同样不叠加。防御下降只有这一招原来的能力阶 −1，只降一次。回合结束损失 `max(1, min(floor(体力上限 / 12), floor(体力上限 * 0.08)))`。十二分之一超过 8% 时用 8%。只剩 1 点体力时会倒下。 |
| 状态里降低速度的持续伤害 | 麻痹 | 不叠加。从下一次行动判定开始算。如果这一回合已经行动过才中招，当回合结束不先扣回合。每次行动开始判定过后，回合结束才减少 1 回合。判定用独立的 `rng()`，小于 0.25 就这一下不能动，异常不因此提前消失。 |
| 定身 | 睡眠 | 命中后再看技能上的概率。成功则下一次行动不能出手，然后睡眠结束。已经睡着时再使用，只提示没有叠加，不会连着再睡一回合。 |

回合末先结算灼伤或中毒的扣血，再结算原来的持续回复和攻击附带的持续伤害。「持续 N 回合」对灼伤和中毒是 N 次回合结束扣血，包含中招的那一回合。麻痹不在没做过行动判定的回合扣持续时间。换人、战斗结束清掉异常、能力阶和护盾，不写进存档。净化会清掉这些异常，并把已经下降的攻击、防御、速度阶拉回 0。

敌方选招时，如果对方已经有同一种异常，这招分数降到 1，低于普通攻击。

界面在对方名字旁显示异常和剩余回合。技能说明里写中文异常名。战斗按钮短按出招。按住大约 450 毫秒只把这招的说明写进战报，不消耗法力，也不进入对手的行动。
