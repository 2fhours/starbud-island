# 存档与版本

## 两套版本号

- 画面版本来自 `package.json`，构建时写进页面角标。当前画面版本是 1.5.1。
- 存档信封版本是存档 JSON 里的 `version`。现在只接受 `1`。它不是画面版本，升级画面不会自动把信封改成 1.4。

## 键

| 键 | 作用 | 清除存档时 |
| --- | --- | --- |
| `xingya-island-save-v1` | 旅程进度 | 删掉 |
| `xingya-island-music` | 音乐开关 | 保留 |
| `xingya-island-music-volume` | 音量 | 保留 |
| `xingya-island-mute` | 音效开关 | 保留 |
| `xingya-island-drag-hint` | 拖动提示是否看过 | 保留 |

不要改这些键的名字。旧设备上的进度靠同一个存档键继续读。

## 信封

```
{ "version": 1, "play": { ... } }
```

`deserialize` 要求 `version` 正好是数字 1，并且有 `play`。其他信封版本整段拒绝，返回空，不会改写成新档，也不会自动删除原来的字符串。标题上的继续按钮在读不到合法进度时不可用。

## 读入时的字段

- 名字取前 8 个字。坐标和方向必须合法。方向只接受上下左右。
- 队伍至少 1 只。物种 id 必须是现有 8 种。等级不是 1 到 30 的数字则这只无效；有效等级用 `floor`。
- 经验缺省或负数时记 0，否则 `floor`。
- 体力缺省时先记 1，再夹到 0 和按当前公式算出的上限之间。上限公式变了，旧体力不按比例重算，只做夹断。
- 攻击、防御、速度阶一律恢复为 0，不保留战斗中的临时阶。
- `aspect` 必须是当前 12 属性之一，否则用物种图鉴属性。
- 五项个体值必须是 0 到 31 的整数。缺了或不合格时，用 uid 算出一组固定个体值，同一 uid 永远得到同一组。已经合格的个体值原样保留。
- 没有个体值的旧档，体力按 1.4 的旧上限比例换到新上限：原来满体力的换成新满体力，原来是 0 的保持 0，中间值按比例四舍五入，结果再夹进 0 和新上限。已经带个体值的档案只把体力夹进新上限，不再按比例重算。
- 法力缺省时补满。已经写下的法力只夹进 0 和新上限。
- `moves` 只留下字符串。再按当前属性和等级过滤：不在已学会技能 id 里的条目丢掉。一条都不剩时，装备该属性的默认四招。旧短 id 不会在这里翻译，所以会走默认装备。
- 图鉴按 8 个物种补齐。队伍里的物种标为见过。
- 星芽球缺省为 0，否则 `max(0, floor(球数))`。
- 委托、训练师标记、拾取物 id、游玩毫秒按布尔或数组收束。缺省就是未完成、未拾取、0 毫秒。

队伍或寄存里只要有一只无法识别，整段存档拒绝。

## 画面版本里和存档有关的变化

| 画面版本 | 存档信封 | 行为 |
| --- | --- | --- |
| 1.4.0 | 1 | 十二属性和 480 个技能进入游戏。存档键没变。旧装备 id 对不上新表时，读档换成默认四招，等级、经验、体力和图鉴属性仍按上一节保留。 |
| 1.4.1 | 1 | 只调整捕捉和遭遇弹框的底栏。不增删存档字段，不改信封版本。 |
| 1.5.0 | 1 | 五维、个体值和法力。旧档仍用同一个键和信封 1。缺个体值时按上一节迁移一次；写回之后再次读取不再重算。 |
| 1.5.1 | 1 | 五行相克改为 2 倍，同一五行的阴阳互克改为双向 1.5 倍。不改存档字段。 |

1.4.0 之前的画面版本没有写进存档。只要信封仍是 1、物种 id 仍是这 8 种，就按上表的读入规则处理。没有更早的自动迁移脚本。
