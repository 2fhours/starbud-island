# 计算公式

函数在 `src/game/stats.ts`、`logic.ts`、`elements.ts`、`skills.ts`、`battle.ts`。概率除非写明百分比，否则是 0 到 1 的比例。`rng()` 在正式游戏里是 `Math.random()`，均匀分布在 `[0, 1)`。测试可以改成固定队列。取整使用 JavaScript 的 `Math.floor` 和 `Math.round`：`floor` 向负无穷，这里的输入都是非负；`round` 是半数向正无穷的常用四舍五入。

复核测试是 `src/game/formula.doc.test.ts`。

## 五维

五行属性决定招式属性和克制。体质、力量、智力、精神、速度是另一套能力，不替代五行。

隐藏量：

- 种族值：物种固定的五项，见设定文档。范围大约 36 到 80，十二种合计大约 270 到 290。星雾岭的四只用同一套五维、伤害和经验公式，不另写等级换算。野生等级和试炼等级是生成参数，见设定文档。
- 个体值：每只芽灵五项各自 0 到 31 的整数。生成时决定，升级、打开面板和再次读档都不重掷。

可见五维：

```
可见值 = floor((种族值 + 个体值) * (level + 8) / 20)
```

推导，全部用 `floor`，系数都是正的：

```
生命上限 = floor(体质 * 8 / 5) + level + 12
法力上限 = floor(精神 * 6 / 5) + level + 6
物攻 = floor(力量 * 3 / 5) + 6
物防 = floor(体质 * 2 / 5) + floor(力量 / 5) + 4
魔攻 = floor(智力 * 3 / 5) + 6
魔防 = floor(智力 * 3 / 10) + floor(精神 * 3 / 10) + 4
出手 = floor(速度 * 7 / 10) + 4
```

临时阶仍是攻击、防御、速度，范围 -3 到 3。阶倍率：非负 `(2 + 阶) / 2`，负阶 `2 / (2 - 阶)`。物攻乘攻击阶，物防乘防御阶。速度点 = `max(1, floor(可见速度 * 速度阶倍率))`。出手比较时，出手值再乘同一个速度阶倍率。魔攻和魔防不吃阶。

| 阶 | -3 | -2 | -1 | 0 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 倍率 | 0.4 | 0.5 | 2/3 | 1 | 1.5 | 2 | 2.5 |

生成时当前体力 = `round(生命上限 * hpRatio)`，再夹到 1 和上限之间。法力从满值开始。

样例：叶角鹿 5 级，五项个体都是 0。种族体质 58、力量 54、智力 56、精神 56、速度 52。

```
体质 = floor(58 * 13 / 20) = 37
力量 = floor(54 * 13 / 20) = 35
智力 = floor(56 * 13 / 20) = 36
精神 = floor(56 * 13 / 20) = 36
速度 = floor(52 * 13 / 20) = 33
生命 = floor(37 * 8 / 5) + 5 + 12 = 76
法力 = floor(36 * 6 / 5) + 5 + 6 = 54
物攻 = floor(35 * 3 / 5) + 6 = 27
物防 = floor(37 * 2 / 5) + floor(35 / 5) + 4 = 25
魔攻 = floor(36 * 3 / 5) + 6 = 27
魔防 = floor(36 * 3 / 10) + floor(36 * 3 / 10) + 4 = 24
出手 = floor(33 * 7 / 10) + 4 = 27
```

样例体质 37。样例生命 76。样例法力 54。样例物攻 27。样例物防 25。

零个体 8 级岩壳龟出手 27，零个体 8 级电绒鼠出手 47。样例出手 27 对 47。

## 经验

```
升级所需 = 18 + level * level * 3
获得经验 = max(8, floor(对方等级 * 物种基础经验 * 训练师倍率 / 7))
```

训练师倍率：训练师战胜利为 1.45，野生胜利或收服为 1。先乘再 `floor`，然后和 8 取最大。

升级时减去当前等级的所需经验，等级加 1。体力和法力都只加上新旧上限的差。体力原来是 0 就保持 0，不满的体力不会因此回满。一次经验可以连升。升到 30 级后剩余经验清零，之后再获得经验只提示已到上限，不加经验。

样例：5 级升级所需 `18 + 25 * 3 = 93`。电绒鼠基础经验 62、野生 5 级，获得 `max(8, floor(5 * 62 / 7)) = floor(44.285…) = 44`。同一对手在训练师战是 `floor(5 * 62 * 1.45 / 7) = floor(64.214…) = 64`。样例经验 93、44、64。

叶角鹿 5 级获得 40 点时，40 < 93，仍是 5 级，经验 40，体力不变。样例经验结余 40。

## 属性倍率

设攻击属性 `A`、防御属性 `D`。三个系数初始都是 1，最后相乘。

1. 五行系数。双方都有金木水火土时才判断，四条互斥：`A` 克 `D` 为 2；`D` 克 `A` 为 0.75；`A` 生 `D` 为 0.85；`D` 生 `A` 为 1.15。否则为 1。纯阴、纯阳没有五行，这一项保持 1。
2. 阴阳系数。同一五行且阴阳相反时为 1.5，双向相同，例如阴金打阳金、阳金打阴金。纯阴打纯阳、纯阳打纯阴也是 1.5。纯阴或纯阳打金木水火土，以及金木水火土打纯阴或纯阳，都不乘这 1.5。其余情况为 1。不再使用旧的「阳打阴 1.1、阴打阳不加」。
3. 同气系数。`A` 和 `D` 是同一个属性 id 时为 0.9，否则为 1。

五行相克要求五行不同，阴阳互克要求五行相同，所以 2 和 1.5 不会乘在同一次攻击上。公式仍然是相乘，只是另一项系数为 1。若将来两条同时成立，结果照样相乘，不另换规则。

```
总倍率 = 五行系数 × 阴阳系数 × 同气系数
先 round(总倍率 × 100) / 100
再夹到 0.75 以上、2.00 以下
```

2.00 和 1.50 都在这个区间里，不会被截成 1.60。当前能出现的最低乘积是受克 0.75。

样例：

| 攻击 | 防御 | 过程 | 结果 |
| --- | --- | --- | --- |
| 阴水 | 阳火 | 水克火，五行 2，阴阳系数 1 | 2 |
| 阴水 | 阴火 | 水克火，阴阳相同，仍是 2 | 2 |
| 阳火 | 阴金 | 火克金，五行 2，不因阳打阴再乘 | 2 |
| 阴金 | 阳金 | 同一行、阴阳相反，阴阳 1.5 | 1.5 |
| 阳金 | 阴金 | 方向相反，仍是 1.5 | 1.5 |
| 阳火 | 阴水 | 被水克，五行 0.75 | 0.75 |
| 阳火 | 阳土 | 火生土 0.85 | 0.85 |
| 阳土 | 阳火 | 得相生 1.15 | 1.15 |
| 阳金 | 阳金 | 同 id 0.9 | 0.9 |
| 纯阳 | 纯阴 | 没有五行，阴阳 1.5 | 1.5 |
| 纯阳 | 阴金 | 纯阳不克五行里的阴 | 1 |

样例倍率 2、1.5、0.75、0.9。

## 伤害

威力不大于 0 的招式不走伤害式。否则：

先把攻击方加成算完，再减去防御方的防御减少。攻和防不先除成一个综合倍率。命中和闪避在这之前判定，没打中就不进这条式子。护盾不放进减法，仍在伤害算完后按原规则吸收。

```
阶后攻击 = 物理 ? 物攻 × 攻击阶倍率 : 魔攻
阶后防御 = 物理 ? 物防 × 防御阶倍率 : 魔防
破防系数 = 破防招式 ? 0.7 : 1
同属性 = 招式属性等于攻击者当前属性 ? 1.2 : 1
浮动半宽 = 初级直击 ? 0.08 : 0.05
浮动 = 1 - 浮动半宽 + rng() × 浮动半宽 × 2
攻击基底 = (威力 × 阶后攻击 / 60) × 同属性 × 属性倍率 × 浮动
攻击加成 = 攻击基底 × (1 + 百分比加成) + 固定加成
百分比减伤后 = 攻击加成 × (1 - 百分比减伤)
固定减伤 = 阶后防御 × 破防系数 + 额外固定减伤
伤害 = 百分比减伤后 - 固定减伤
伤害 = 差 ≥ 1 ? floor(差) : 1
```

属性倍率就是上一节的总倍率，五行 2 倍和阴阳 1.5 倍都在这里乘完，减伤阶段不再改这两个数。百分比加成上限 0.50，百分比减伤上限 0.60，小于 0 的按 0。固定加成和额外固定减伤小于 0 的按 0。中间过程不取整。只在最后，差大于等于 1 时做一次 `floor`。差小于 1 时伤害定为 1，战报写「没能破开防御」。浮动均匀落在 `[1 - 半宽, 1 + 半宽)`；`rng()` 取 1 时刚好到上界，正式随机取不到 1。

固定加成和百分比加成来自技能与当次战斗里已经挂上的辅助。反震招额外增加 6 点。初级以外的直击提高 10%。辅助里的能力提升会在本场留下 8% 伤害提高和 4 点固定加成，换下或战斗结束清掉。护卫里的加防会在本场留下 10% 减伤和 4 点额外固定减伤。这些数不写入存档；没有就是 0。护盾不是这两种减伤，仍在伤害确定后吸收。阶是能力阶，在进入这条式子之前先乘进物攻、物防或魔攻、魔防，不算进上面的百分比。

护盾再从这点伤害里扣，剩下的才减体力。体力最低 0。反震是 `max(1, floor(伤害 * 0.1))`，使用者体力大于 1 才扣，并且不会扣到 1 以下。

物理招用物攻对物防，魔法招用魔攻对魔防。直击和反震是物理，破防和附带持续伤害的攻击是魔法。普通攻击是威力 32 的物理直击，不消耗法力，也没有冷却，五行用使用者当前属性。

界面说明和这条分支用同一个分类。攻击招里 `kind` 为 `magic` 时走魔攻对魔防，其余直接伤害走物攻对物防。威力不大于 0，或类别不是攻击的招，不进这条伤害式，界面标成辅助。说明里的「以物攻对抗物防」「以魔攻对抗魔防」就是上面阶后攻击和阶后防御的这一支，不另写一套倍率。五行 2 倍、阴阳 1.5 倍、先攻击加成再减伤、命中闪避和最小伤害都不因这个分类改数。

样例都是 8 级、个体全 0、攻击阶和防御阶为 0，除非另外写出。初级直击在 `rng = 0.5` 时浮动正好是 1。没有写出的固定加成、百分比加成、百分比减伤和额外固定减伤都是 0。

普通命中：焰尾狐改成纯阳，用纯阳初级直击，威力 46，打电绒鼠。倍率是 1，物攻 37，物防 25。

```
攻击加成 = 46 × 37 / 60 × 1.2 × 1 × 1 = 34.04
防御减少 = 25
伤害 = floor(34.04 - 25) = 9
```

样例普通 9。

只有固定加成：同一击再加 4 点。攻击加成变成 34.04 + 4 = 38.04，伤害 = floor(38.04 - 25) = 13。样例固定 13。

只有百分比加成：同一击提高 10%。攻击加成 = 34.04 × 1.1 = 37.444，伤害 = floor(37.444 - 25) = 12。样例百分比 12。

两边的固定和百分比一起上：攻击提高 10% 再加 4 点，减伤先降 10% 再额外减 4 点。

```
攻击加成 = 34.04 × 1.1 + 4 = 41.444
百分比减伤后 = 41.444 × 0.9 = 37.2996
固定减伤 = 25 + 4 = 29
伤害 = floor(37.2996 - 29) = 8
```

样例两边 8。

五行 2 倍：露珠蛙用「露弹」打焰尾狐。物攻 27，物防 28，倍率 2。

```
攻击加成 = 46 × 27 / 60 × 1.2 × 2 × 浮动
rng = 0.5 时攻击加成 = 49.68，伤害 = floor(49.68 - 28) = 21
rng = 0 时浮动 0.92，伤害 = 17
rng = 1 时浮动 1.08，伤害 = 25
```

样例伤害 21。样例伤害低 17。样例伤害高 25。

阴阳 1.5 倍：风铃鸟为阴金，用电绒鼠的阳金当对手，初级直击威力 46。物攻 30，物防 25，倍率 1.5，浮动 1。

```
攻击加成 = 46 × 30 / 60 × 1.2 × 1.5 × 1 = 41.4
伤害 = floor(41.4 - 25) = 16
```

样例阴阳 16。

两者同时：现行属性对里，五行 2 和阴阳 1.5 不会出现在同一次攻击。公式仍先把两项乘进攻击加成，再减防御。用露珠蛙打焰尾狐的同一组物攻、物防和威力，浮动取 1：

```
攻击加成 = 46 × 27 / 60 × 1.2 × 2 × 1.5 × 1 = 74.52
防御减少 = 28
伤害 = floor(74.52 - 28) = 46
```

样例同时 46。

高防御：露珠蛙用「露弹」、`rng = 0.5` 打防御阶 +3 的岩壳龟。倍率是被克 0.75。岩壳龟物防 35，阶倍率 2.5，防御减少 87.5。攻击加成 18.63，小于防御减少，伤害定为 1。样例未破防 1。

同一招对叶角鹿是相生 0.85。攻击加成 21.114，叶角鹿物防 30，差小于 1，伤害也是 1。样例相生伤害 1。

只把力量个体从 0 提到 31 时，露弹对焰尾狐的伤害从 21 升到 49。只把智力个体从 0 提到 31 时，初级魔法「锐羽」对焰尾狐从 60 升到 91，物理伤害不变。样例物理 49。样例魔法 91。

## 治疗、护盾、持续和定身

单次回复：

```
回复量 = min(floor(体力上限 * min(0.4, 招式比例)), 体力上限 - 当前体力)
```

比例再高，单次也不超过上限的 40%。生成出的回复比例目前最大是 0.36，40% 这条仍然有效。

护盾：

```
本次 = max(1, floor(体力上限 * 招式比例))
护盾 = min(floor(体力上限 * 0.35), 原护盾 + 本次)
```

持续回复在挂上时把比例收成 `min(0.08, 招式比例)`。每跳：

```
回复 = min(floor(体力上限 * 0.08), floor(体力上限 * 已收比例), 所缺体力)
```

持续伤害比例由招式写成至少 0.06，多段取较大值。每跳：

```
损失 = max(1, min(floor(体力上限 * 0.08), floor(体力上限 * max(0.04, 比例))))
```

体力可以因此到 0。单跳不超过上限的 8%，也不低于 1。

攻击和状态招在效果前先判定命中，再判定闪避。治疗、防御、辅助不走这两步。

```
速度点 = max(1, floor(可见速度 * 速度阶倍率))
命中率 = clamp(0.78 + 精神 / 480 + 速度点 / 700, 0.78, 0.96)
闪避率 = clamp(0.03 + 速度点 / 650, 0.03, 0.16)
```

`rng() >= 命中率` 时战报写「没有命中」。否则 `rng() < 闪避率` 时写「闪避了攻击」。两次都用独立的 `rng()`。面板上的命中、闪避百分比用未加阶的可见速度，方便对照；进战斗后速度阶会改变速度点。样例命中下限 0.78。样例闪避上限 0.16。

法力消耗：初级直击为 0，其余初级 4，中级 8，高级 12，神级 18。法力不足时不扣法力、不写冷却。命中失败和闪避仍扣法力并写冷却。回合末若法力未满，恢复 `max(1, floor(法力上限 * 0.05))`。没有可支付的技能时，双方都能用普通攻击，避免无法行动。

定身：先通过命中和闪避，再看定身。对方已经定身则本次不刷新。否则 `rng() < 定身概率` 时定住 1 回合。定身概率只对定身招有效。

行动开始时先把该战斗者的全部冷却减 1，减到 0 就删除，然后再看定身。定身会跳过这一次行动，并在这次结算里清掉。冷却因此会在被定住的那一次行动里先减 1。

使用技能时，若该招剩余冷却大于 0，只提示还在冷却，不改写冷却。否则结算效果；冷却大于 0 的招在结算末写成技能上的冷却值。神级写成 3 时，接下来自己的两次行动开始时仍大于 0，第三次行动开始时减到 0，可以再用。

能力阶每次 +1 或 -1，再夹到 -3 至 3。净化清除持续伤害、定身，以及负数的攻击、防御、速度阶，不清除护盾和正阶。

样例：叶角鹿 5 级、个体全 0，上限 76，当前体力 `round(76 * 0.4) = 30`。初级回复比例 0.14。

```
回复量 = min(floor(76 * 0.14), 76 - 30) = min(10, 46) = 10
```

体力变为 40。样例回复 10。

同一只满体力时，初级护盾一次获得 `floor(76 * 0.14) = 10`。护盾上限 `floor(76 * 0.35) = 26`。连续使用停在 26。样例护盾 26。

24 级叶角鹿、个体全 0，上限 183。当前体力 `round(183 * 0.2) = 37`。神级回复比例 0.32：

```
回复量 = min(floor(183 * 0.32), 183 - 37) = min(58, 146) = 58
```

样例神级回复 58。

## 进化成长

进化不改伤害、治疗、命中和经验公式。等级上限是 40。`expToNext` 仍是 `18 + 等级² × 3`。从 34 级升到 35 级需要 `18 + 34² × 3 = 3486` 点经验，所以 35 级的进化门槛可以练到，不是文案上的死条件。到 40 级后经验记 0，并提示已经到成长上限。

种族值只在进化形态上按阶段增加，基础种的表不变。`stage` 从 1 起算：

```
步数 = stage - 1
每项种族值 = 基础项 + 步数 × 4
最高项再加 步数 × 6
```

最高项按体质、力量、智力、精神、速度的顺序取第一个最大值。结果是整数，不再取整。样例叶角鹿体质 58 为最高项。翠枝鹿体质 68，森冕鹿体质 78。其余四项翠枝鹿各加 4，森冕鹿各加 8。

基础经验 `基础 + 步数 × 8`。捕捉率 `max(40, 基础 - 步数 × 20)`。

## 技能生成

每个属性、每一类有 8 个名字，下标 `i = 阶序号 * 2 + 槽`。阶序号初级 0、中级 1、高级 2、神级 3，槽是 0 或 1，所以 `i` 为 0 到 7。

| i | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 威力 | 46 | 52 | 62 | 68 | 78 | 84 | 94 | 100 |
| 比例 | 0.14 | 0.16 | 0.20 | 0.22 | 0.26 | 0.28 | 0.32 | 0.36 |
| 持续回合表 | 2 | 2 | 2 | 1 | 3 | 1 | 3 | 1 |
| 定身概率表 | 0.70 | 0.75 | 0.80 | 0.55 | 0.85 | 0.60 | 0.90 | 0.65 |

攻击招使用威力，比例改记 0；附带持续伤害的比例固定记 0.06。防御、治疗、辅助、状态的威力记 0，使用比例。持续回合只留给附带持续伤害、持续回复、持续伤害状态和定身。定身回合固定写成 1，不使用表里的持续回合。定身概率只用在定身招。

冷却：神级 3；高级且类别是治疗或状态时为 2；否则 0。攻击招里直击和反震是物理，破防和附带持续伤害是魔法。防御、治疗、辅助、状态的威力是 0，不标成物理或魔法。法力消耗见上面的五维一节。

总数 `12 * 5 * 8 = 480`。每属性 40。样例技能总数 480。

## 行动顺序和敌方选招

双方都能行动时：

```
玩家出手 ≥ 对方出手 时，玩家先动
否则对方先动
```

出手先乘速度阶。相等时玩家先。样例：零个体 8 级岩壳龟出手 27，零个体 8 级电绒鼠出手 47，电绒鼠先动。两只个体相同的 8 级叶角鹿出手相同，玩家先动。

敌方跳过冷却中和法力不够的招。若一招都用不了，就用普通攻击。其余在可用招里取最高分，同分留先写上的那招：

| 类别 | 分数 |
| --- | --- |
| 治疗 | 自身体力 ≤ ceil(上限 * 0.45) 时 80，否则 6 |
| 防御 | 护盾已大于上限 * 0.2 时 4，否则 36 |
| 辅助 | 28 |
| 状态 | 对方已定身且这招是定身时 2，否则 34 |
| 攻击 | max(1, 威力) * 属性倍率 |

## 捕捉、光环和逃跑

光环缩放每 1.35 秒循环一次：`缩放 = 1.85 - ((时间 mod 1.35) / 1.35) * 1.3`，从 1.85 线性到 0.55。

时机按距离 `|缩放 - 1|`，用小于等于归入更准的一档：

| 距离 | ≤ 0.07 | ≤ 0.15 | ≤ 0.26 | 更大 |
| --- | --- | --- | --- | --- |
| 时机 | 完美 | 不错 | 差一点 | 错过 |
| 时机倍率 | 1.55 | 1.18 | 0.88 | 0.42 |

距离正好等于 0.07、0.15、0.26 时留在左边那一档。小数 1.07 在 JavaScript 里离 1 略大于 0.07，所以判成不错；1.15 判成不错，1.1500001 起算差一点；1.26 仍是差一点。

```
体力系数 = 0.22 + (1 - clamp(当前体力 / 上限, 0, 1)) * 0.55
成功率 = clamp((捕捉率 / 255) * 体力系数 * 时机倍率 * 1.85, 0.06, 0.92)
```

`rng() < 成功率` 则成功。界面显示 `round(成功率 * 100)` 的整数百分比。球在掷出时先减 1，失败不退回。

样例：电绒鼠捕捉率 145，满体力，完美。

```
体力系数 = 0.22
成功率 = (145 / 255) * 0.22 * 1.55 * 1.85 = 0.3587186274509804
显示 36%
```

同一只满体力、错过节奏：`0.3587186274509804 * 0.42 / 1.55 = 0.09720117647058824`，显示 10%。体力比例 0.2、完美：体力系数 0.66，未夹断前约 1.076，夹到上限 0.92，显示 92%。样例捕捉 0.3587186274509804。样例捕捉上限 0.92。

失败后的逃跑：

```
逃跑率 = clamp(0.12 + 此前失败次数 * 0.16, 0.12, 0.72)
```

第一次失败用 0 次此前失败，逃跑率 0.12；然后是 0.28、0.44、0.60，从第 5 次失败起保持 0.72。`rng() < 逃跑率` 则野生芽灵离开。样例逃跑 0.12。

收服成功时，野外把野生经验给领队；战斗中收服把野生经验给当前上场的我方。训练师胜利用训练师倍率。经验公式见上。

## 自动继续

纯说明文字和战报：

```
测试模式等待 = 45 毫秒
否则等待 = min(4800, max(1500, 800 + 字符数 * 70))
```

字符按 Unicode 码点计。空文本或很短的句子是 1500 毫秒，很长的句子到 4800 毫秒封顶。样例短句「结果会自动继续」7 个字：`800 + 7 * 70 = 1290`，再抬到 1500。样例等待 1500。80 个字是 `800 + 5600 = 6400`，再压到 4800。样例等待上限 4800。

点文字会立刻跳过这一句。捕捉、取消、技能、逃跑、休息和清除存档不使用这条自动选择。
