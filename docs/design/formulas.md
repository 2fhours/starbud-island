# 计算公式

函数都在 `src/game/logic.ts`、`src/game/elements.ts`、`src/game/skills.ts`、`src/game/battle.ts`。概率除非写明百分比，否则是 0 到 1 的比例。`rng()` 在正式游戏里是 `Math.random()`，均匀分布在 `[0, 1)`。测试可以改成固定队列。取整使用 JavaScript 的 `Math.floor` 和 `Math.round`：`floor` 向负无穷，这里的输入都是非负；`round` 是半数向正无穷的常用四舍五入。

复核测试是 `src/game/formula.doc.test.ts`。

## 等级能力

变量：

- `base`：物种基础值，见设定文档的表。体力、攻击、防御、速度各有一个。
- `level`：整数，生成和读档都限制在 1 到 30。
- `stage`：攻击、防御、速度的临时阶，每项独立，范围 -3 到 3。进战斗时清零，换下或读档也清零。

```
体力上限 = floor(base体力 * 2 * level / 40) + level + 12
能力值 = floor(base * 2 * level / 45) + 6
```

能力值用于攻击、防御、速度。阶数先 `round` 再夹到 -3 至 3：

```
阶 ≥ 0 时，阶倍率 = (2 + 阶) / 2
阶 < 0 时，阶倍率 = 2 / (2 - 阶)
```

| 阶 | -3 | -2 | -1 | 0 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 倍率 | 0.4 | 0.5 | 2/3 | 1 | 1.5 | 2 | 2.5 |

生成时当前体力 = `round(体力上限 * hpRatio)`，再夹到 1 和上限之间。满体力的 `hpRatio` 是 1。

速度阶不参与行动顺序。顺序只比上式的速度能力值，不含阶倍率。

样例：叶角鹿 5 级，基础体力 50、攻击 52、防御 46、速度 48。

```
体力上限 = floor(50 * 2 * 5 / 40) + 5 + 12 = floor(12.5) + 17 = 29
攻击 = floor(52 * 10 / 45) + 6 = floor(11.555…) + 6 = 17
防御 = floor(46 * 10 / 45) + 6 = floor(10.222…) + 6 = 16
速度 = floor(48 * 10 / 45) + 6 = floor(10.666…) + 6 = 16
```

样例体力 29。样例攻击 17。

电绒鼠 8 级速度基础值 72：`floor(72 * 16 / 45) + 6 = floor(25.6) + 6 = 31`。岩壳龟 8 级速度基础值 24：`floor(24 * 16 / 45) + 6 = floor(8.533…) + 6 = 14`。样例速度 31 对 14。

## 经验

```
升级所需 = 18 + level * level * 3
获得经验 = max(8, floor(对方等级 * 物种基础经验 * 训练师倍率 / 7))
```

训练师倍率：训练师战胜利为 1.45，野生胜利或收服为 1。先乘再 `floor`，然后和 8 取最大。

升级时减去当前等级的所需经验，等级加 1，当前体力加上新旧上限的差，再夹到 1 和新上限。一次经验可以连升。升到 30 级后剩余经验清零，之后再获得经验只提示已到上限，不加经验。

样例：5 级升级所需 `18 + 25 * 3 = 93`。电绒鼠基础经验 62、野生 5 级，获得 `max(8, floor(5 * 62 / 7)) = floor(44.285…) = 44`。同一对手在训练师战是 `floor(5 * 62 * 1.45 / 7) = floor(64.214…) = 64`。样例经验 93、44、64。

叶角鹿 5 级获得 40 点时，40 < 93，仍是 5 级，经验 40，体力不变。样例经验结余 40。

## 属性倍率

设攻击属性 `A`、防御属性 `D`。初始倍率 1。

1. 若双方都不是纯阴或纯阳：`A` 克 `D` 乘 1.5；`D` 克 `A` 乘 0.75；`A` 生 `D` 乘 0.85；`D` 生 `A` 乘 1.15。这四条互斥。
2. 纯阳打纯阴，或纯阴打纯阳，乘 1.2。否则若 `A` 为阳且 `D` 为阴，乘 1.1。阴打阳不加。
3. 若 `A` 和 `D` 是同一个属性 id，再乘 0.9。
4. `round(倍率 * 100) / 100`。
5. 夹到 0.70 以上、1.60 以下。

样例：

| 攻击 | 防御 | 过程 | 结果 |
| --- | --- | --- | --- |
| 阴水 | 阳火 | 水克火 1.5，阴打阳不加 | 1.5 |
| 阳火 | 阴水 | 受克 0.75，阳打阴 1.1，0.825 四舍五入 | 0.83 |
| 阳火 | 阴金 | 火克金 1.5，阳打阴 1.1，1.65 再夹断 | 1.6 |
| 阳火 | 阳土 | 火生土 0.85 | 0.85 |
| 阳土 | 阳火 | 得土所生之火 1.15 | 1.15 |
| 阳金 | 阳金 | 同 id 0.9 | 0.9 |
| 纯阳 | 纯阴 | 只乘 1.2 | 1.2 |

样例倍率 1.5、0.83、1.6、0.9。

## 伤害

威力不大于 0 的招式不走伤害式。否则：

```
攻击力 = 攻击能力值 * 攻击阶倍率
防御力 = max(1, 防御能力值 * 防御阶倍率 * 破防系数)
破防系数 = 破防招式 ? 0.7 : 1
浮动半宽 = 初级直击 ? 0.08 : 0.05
浮动 = 1 - 浮动半宽 + rng() * 浮动半宽 * 2
原始 = (((2 * 攻击等级) / 5 + 2) * 威力 * 攻击力) / 防御力 / 32 + 2
同属性 = 招式属性等于攻击者当前属性 ? 1.2 : 1
伤害 = max(1, floor(原始 * 同属性 * 属性倍率 * 浮动))
```

中间的乘除不取整。只在最后 `floor`，并且至少 1。浮动均匀落在 `[1 - 半宽, 1 + 半宽)`；`rng()` 取 1 时刚好到上界，正式随机取不到 1。

护盾先扣伤害，剩下的再扣体力。体力最低 0。反震是 `max(1, floor(伤害 * 0.1))`，使用者体力大于 1 才扣，并且不会扣到 1 以下。

样例：露珠蛙 8 级、锁定阴水，用初级直击「露弹」威力 46，打 8 级焰尾狐（阳火）。攻击能力值 23，对方防御能力值 20，阶都是 0。属性倍率 1.5，同属性 1.2，初级直击半宽 0.08。

```
原始 = (((16 / 5) + 2) * 46 * 23) / 20 / 32 + 2 = 10.59625
rng = 0.5 时浮动 = 1
伤害 = floor(10.59625 * 1.2 * 1.5 * 1) = floor(19.07325) = 19
rng = 0 时浮动 = 0.92，伤害 = 17
rng = 1 时浮动 = 1.08，伤害 = 20
```

同一招对 8 级叶角鹿（阳木）是相生 0.85，`rng = 0.5` 时伤害 10。样例伤害 19。样例伤害低 17。样例伤害高 20。样例相生伤害 10。

## 治疗、护盾、持续和定身

单次回复：

```
回复量 = min(floor(体力上限 * min(0.4, 招式比例)), 体力上限 - 当前体力)
```

比例再高，单次也不超过上限的 40%。生成出的回复比例目前最大是 0.36，40% 这条仍然有效。

护盾：

```
本次 = max(1, floor(体力上限 * 招式比例))
护盾 = min(floor(体力上限 * 0.35), 原护盾 + 本次)
```

持续回复在挂上时把比例收成 `min(0.08, 招式比例)`。每跳：

```
回复 = min(floor(体力上限 * 0.08), floor(体力上限 * 已收比例), 所缺体力)
```

持续伤害比例由招式写成至少 0.06，多段取较大值。每跳：

```
损失 = max(1, min(floor(体力上限 * 0.08), floor(体力上限 * max(0.04, 比例))))
```

体力可以因此到 0。单跳不超过上限的 8%，也不低于 1。

定身：若对方已经处于定身，本次不刷新。否则 `rng() < 定身概率` 时把定身记为 1 回合，失败则挣开。定身概率只对定身招有效，其他招的 `chance` 固定为 1，不另做命中检定。

行动开始时先把该战斗者的全部冷却减 1，减到 0 就删除，然后再看定身。定身会跳过这一次行动，并在这次结算里清掉。冷却因此会在被定住的那一次行动里先减 1。

使用技能时，若该招剩余冷却大于 0，只提示还在冷却，不改写冷却。否则结算效果；冷却大于 0 的招在结算末写成技能上的冷却值。神级写成 3 时，接下来自己的两次行动开始时仍大于 0，第三次行动开始时减到 0，可以再用。

能力阶每次 +1 或 -1，再夹到 -3 至 3。净化清除持续伤害、定身，以及负数的攻击、防御、速度阶，不清除护盾和正阶。

样例：叶角鹿 5 级上限 29、当前体力 `round(29 * 0.4) = 12`。初级回复比例 0.14。

```
回复量 = min(floor(29 * 0.14), 29 - 12) = min(4, 17) = 4
```

体力变为 16。样例回复 4。

同一只满体力时，初级护盾比例 0.14，一次获得 `floor(29 * 0.14) = 4`。护盾上限 `floor(29 * 0.35) = 10`。连续使用停在 10，不会到 12。样例护盾 10。

24 级叶角鹿上限 `floor(50 * 2 * 24 / 40) + 24 + 12 = 96`。当前体力 `round(96 * 0.2) = 19`。神级回复比例 0.32：

```
回复量 = min(floor(96 * 0.32), 96 - 19) = min(30, 77) = 30
```

样例神级回复 30。

## 技能生成

每个属性、每一类有 8 个名字，下标 `i = 阶序号 * 2 + 槽`。阶序号初级 0、中级 1、高级 2、神级 3，槽是 0 或 1，所以 `i` 为 0 到 7。

| i | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 威力 | 46 | 52 | 62 | 68 | 78 | 84 | 94 | 100 |
| 比例 | 0.14 | 0.16 | 0.20 | 0.22 | 0.26 | 0.28 | 0.32 | 0.36 |
| 持续回合表 | 2 | 2 | 2 | 1 | 3 | 1 | 3 | 1 |
| 定身概率表 | 0.70 | 0.75 | 0.80 | 0.55 | 0.85 | 0.60 | 0.90 | 0.65 |

攻击招使用威力，比例改记 0；附带持续伤害的比例固定记 0.06。防御、治疗、辅助、状态的威力记 0，使用比例。持续回合只留给附带持续伤害、持续回复、持续伤害状态和定身。定身回合固定写成 1，不使用表里的持续回合。定身概率只用在定身招。

冷却：神级 3；高级且类别是治疗或状态时为 2；否则 0。

总数 `12 * 5 * 8 = 480`。每属性 40。样例技能总数 480。

## 行动顺序和敌方选招

双方都能行动时：

```
玩家速度能力值 ≥ 对方速度能力值 时，玩家先动
否则对方先动
```

相等时玩家先。样例：岩壳龟 8 级速度 14，电绒鼠 8 级速度 31，电绒鼠先动。两只 8 级叶角鹿速度都是 23，玩家先动。

敌方在未冷却的已装备招里取最高分，同分留先写上的那招：

| 类别 | 分数 |
| --- | --- |
| 治疗 | 自身体力 ≤ ceil(上限 * 0.45) 时 80，否则 6 |
| 防御 | 护盾已大于上限 * 0.2 时 4，否则 36 |
| 辅助 | 28 |
| 状态 | 对方已定身且这招是定身时 2，否则 34 |
| 攻击 | max(1, 威力) * 属性倍率 |

## 捕捉、光环和逃跑

光环缩放每 1.35 秒循环一次：`缩放 = 1.85 - ((时间 mod 1.35) / 1.35) * 1.3`，从 1.85 线性到 0.55。

时机按距离 `|缩放 - 1|`，用小于等于归入更准的一档：

| 距离 | ≤ 0.07 | ≤ 0.15 | ≤ 0.26 | 更大 |
| --- | --- | --- | --- | --- |
| 时机 | 完美 | 不错 | 差一点 | 错过 |
| 时机倍率 | 1.55 | 1.18 | 0.88 | 0.42 |

距离正好等于 0.07、0.15、0.26 时留在左边那一档。小数 1.07 在 JavaScript 里离 1 略大于 0.07，所以判成不错；1.15 判成不错，1.1500001 起算差一点；1.26 仍是差一点。

```
体力系数 = 0.22 + (1 - clamp(当前体力 / 上限, 0, 1)) * 0.55
成功率 = clamp((捕捉率 / 255) * 体力系数 * 时机倍率 * 1.85, 0.06, 0.92)
```

`rng() < 成功率` 则成功。界面显示 `round(成功率 * 100)` 的整数百分比。球在掷出时先减 1，失败不退回。

样例：电绒鼠捕捉率 145，满体力，完美。

```
体力系数 = 0.22
成功率 = (145 / 255) * 0.22 * 1.55 * 1.85 = 0.3587186274509804
显示 36%
```

同一只满体力、错过节奏：`0.3587186274509804 * 0.42 / 1.55 = 0.09720117647058824`，显示 10%。体力比例 0.2、完美：体力系数 0.66，未夹断前约 1.076，夹到上限 0.92，显示 92%。样例捕捉 0.3587186274509804。样例捕捉上限 0.92。

失败后的逃跑：

```
逃跑率 = clamp(0.12 + 此前失败次数 * 0.16, 0.12, 0.72)
```

第一次失败用 0 次此前失败，逃跑率 0.12；然后是 0.28、0.44、0.60，从第 5 次失败起保持 0.72。`rng() < 逃跑率` 则野生芽灵离开。样例逃跑 0.12。

收服成功时，野外把野生经验给领队；战斗中收服把野生经验给当前上场的我方。训练师胜利用训练师倍率。经验公式见上。

## 自动继续

纯说明文字和战报：

```
测试模式等待 = 45 毫秒
否则等待 = min(4800, max(1500, 800 + 字符数 * 70))
```

字符按 Unicode 码点计。空文本或很短的句子是 1500 毫秒，很长的句子到 4800 毫秒封顶。样例短句「结果会自动继续」7 个字：`800 + 7 * 70 = 1290`，再抬到 1500。样例等待 1500。80 个字是 `800 + 5600 = 6400`，再压到 4800。样例等待上限 4800。

点文字会立刻跳过这一句。捕捉、取消、技能、逃跑、休息和清除存档不使用这条自动选择。
