# 星芽岛

一款在浏览器里直接游玩的原创小岛冒险。你在星芽岛上走动，遇见自己散步的芽灵，用星芽球邀请它们同行，也可以进行回合对战。画面、生物和地名都是原创的，和任何既有宠物对战作品没有角色或地图对应关系。

游戏是纯静态页面，构建结果在 `dist/`。GitHub Pages 的项目站点路径配置为 `/starbud-island/`。

## 本地运行

```bash
npm install
npm run dev
```

开发地址是 [http://127.0.0.1:43123/starbud-island/](http://127.0.0.1:43123/starbud-island/)。这是你自己电脑上的地址，不是公开试玩链接。

```bash
npm test
npm run build
npm run check:dist
npm run preview
```

预览地址是 [http://127.0.0.1:43124/starbud-island/](http://127.0.0.1:43124/starbud-island/)。浏览器流程测试：

```bash
npm run build
npm run test:browser
```

## 操作

- 电脑：WASD 或方向键移动，E / 空格 / 回车交谈，Esc 返回，数字键 1 到 4 使用已装备的技能。
- 手机：左下角摇杆，也可以在地图上按住拖动。右下角是交谈，菜单在右上角。
- 靠近野生芽灵就会遇见。捕捉、对战、离开、投掷和先不扔都要自己点。
- 星芽驿可以治疗。球少于 8 个时，休息会补到 8 个。
- 进度自动写在这台设备的 localStorage 里。标题画面可以继续，清除存档前会要求确认。

设定和计算公式在 [docs/design/README.md](docs/design/README.md)。改规则时要同步那里的公式和样例。

## 已实现

- 可探索小岛：草地、小镇、星芽驿、湖、树林、道路、碰撞和跟随摄像机
- 键盘、摇杆和地图拖动
- 8 种原创芽灵，金木土水火的阴阳共 12 属性，另有体质、力量、智力、精神、速度；480 个技能分物理和魔法
- 初始伙伴三选一，伙伴跟随
- 可见的野生芽灵、节奏圈捕捉、成功率提示、星芽球消耗
- 回合对战、更换伙伴、经验与升级
- 队伍、图鉴、背包、委托、五行说明和技能图鉴
- 向导青禾与试炼官岚川
- 治疗、补球和地面上的星芽球
- 本地自动存档、继续游戏、确认后清除
- 程序生成的音乐和短音效，可关闭
- 2.5D 与 3D 预览页，不写这趟旅程的存档

## 部署产物

`npm run build` 生成 `dist/`。其中 `index.html` 和脚本样式都从 `/starbud-island/` 加载，可直接作为 GitHub Pages 项目站点。

仓库里的 `.github/workflows/pages.yml` 会在推送到 `main` 时运行测试、构建，并用 GitHub Actions 发布 Pages。首次需要在仓库设置里把 Pages 的构建来源选成 GitHub Actions。工作流成功之后，页面才会出现在 `https://2fhours.github.io/starbud-island/`。在确认该地址返回游戏页之前，不要把它当成已经上线。

源码也可以只把 `dist/` 目录作为静态文件放到任何支持子路径 `/starbud-island/` 的静态托管上。
